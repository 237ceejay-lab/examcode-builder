ExamCode Builder — User Manual
A complete guide to using every feature of the app. Use the quick-links below to jump to any section.
📑 Quick Navigation
🔑 Getting Started
🔒 Signing In
ExamCode Builder uses a university-managed account. You cannot register yourself — your account is created by the system administrator. Contact your admin to get your login credentials.
1
Open the app. The Sign In screen appears automatically.
2
Enter your email address and password provided by the administrator.
3
Tap Sign In. The app loads your personal workspace.
Tip: After 12 hours of inactivity you are automatically signed out for security. Simply sign in again — your data is safely stored.
📱 Installing on Your Device
ExamCode Builder can be installed as a standalone app on phones, tablets, and desktops — no app store required.
1
Android / Desktop Chrome: A banner or Install button appears in the top navigation bar. Tap it and follow the prompt.
2
iPhone / iPad (Safari): Tap the Share icon at the bottom of Safari, then tap "Add to Home Screen".
3
You can also go to Settings → Install App to find the install button and iOS instructions at any time.
📈 Overview Page
📈 What You See on the Dashboard
The Overview page is your home screen. It shows a summary of all your work at a glance.
•
Quick Actions: Buttons to jump directly to the Builder, Files, or Lookup pages.
•
System Overview (KPIs): Total files, total matricules entered, folders, and unified folders you have access to.
•
Matricule Patterns: A breakdown of student levels detected across all your saved files, based on their matricule prefix.
•
Recent Files: Your last-modified documents. Click any file to open it in the Builder.
•
In-Progress Session: If the Builder has unsaved work, a Resume button appears here so you can return to it quickly.
•
Course Summary: A list of all unique courses found across your saved files.
✏️ Builder
📄 What the Builder Does
The Builder is the main working area. You use it to create an exam answer sheet — setting up a course, generating a table of exam codes, then filling in each student's matricule number either by typing or speaking.
▶ Step-by-Step: Creating an Exam Sheet
1
Course Code: Type the course code (e.g. CUCH2101). If you have saved this course before, suggestions appear automatically — tap one to fill the title too.
2
Course Title: Type the full course name (e.g. Functional Chinese). This is included in the exported CSV filename.
3
Prefix: The short code that appears before each exam number (e.g. UT). Exam codes will look like UT001, UT002, etc.
4
# Scripts: How many students are sitting the exam. This determines how many rows the table will have.
5
Click Generate Table. The table appears on the right with one row per student, numbered exam codes already filled in.
6
Fill in the Matricule column — either by typing manually in each cell, or using Voice Input (see the Voice section below).
7
When every matricule is filled, click Done — Close & New at the bottom. The document is saved to your Files and the Builder resets for the next course.
Preview box: Before generating the table, the preview box shows a sample exam code so you can verify the format looks correct.
📋 Typing Matricules Manually
Click any cell in the Matricule column and type the student's number. Navigation tips:
•
Press Enter or ↓ to move to the next row.
•
Press ↑ to move to the previous row.
•
If Enforce Character Limit is on in Settings, the cell stops accepting input once the matricule reaches the configured length.
Auto-prefix: If you have set a Matricule Prefix (e.g. UBa25R0) and Auto-prepend prefix is on in Settings, focusing an empty cell automatically fills in the prefix so you only need to type the trailing digits.
💾 Saving Your Work
Your work is auto-saved to the cloud every 30 seconds (if Auto-Save is on in Settings). You can also save manually at any time:
•
Save to Files (sidebar button): saves a snapshot of the current work to your Files library without closing the Builder.
•
Done — Close & New (bottom bar): saves the finished document, clears the Builder, and resets it for the next course.
•
Discard: closes the document without saving. A confirmation dialog appears first.
•
Export CSV: downloads the current table as a .csv file directly to your device.
Note: If the Builder shows unsaved data when you sign out or close the browser, re-open the app and go to the Overview page — an In-Progress Session card will appear with a Resume button.
🎤 Voice Input
🎤 Starting and Stopping Voice Input
Voice input lets you fill the entire matricule column hands-free by reading student numbers aloud. The app uses your device's microphone and speech recognition.
1
In the Builder, tap the microphone button (🎤) in the voice bar. The button turns red and the status bar says "Listening". Your browser may ask for microphone permission the first time — allow it.
2
Speak the trailing digits of the first student's matricule clearly. If a Matricule Prefix is set and Auto-prepend prefix is on, the prefix is added automatically — you only need to speak the part after it.
3
After you stop speaking, the system waits for the silence timeout (adjustable slider, default 1 second) and then automatically advances to the next row, ready for the next student.
4
Tap the microphone button again (or it stops automatically on the last row) to end voice input.
Screen stays on: While you are filling matricules the screen will not turn off. It will automatically release after 10 minutes of inactivity.
⏱ Silence Timeout Slider
The Silence Timeout controls how long the system waits after you stop speaking before moving to the next row. Adjust it in the Builder's left panel:
•
Drag the slider left for a shorter pause (minimum 50ms — almost instant). Good for fast, confident readers.
•
Drag the slider right for a longer pause (up to 4 seconds). Good if you read slowly or need time between students.
•
After adjusting, click Apply Changes to activate the new timeout. A confirmation toast appears.
🔄 Smart Voice Corrections
Several special voice commands let you correct mistakes without stopping or using the keyboard:
1. Year Correction (while in a cell)
If a cell already contains a matricule like UBa25R0321 and you say a year-only pattern such as UBa23, the system replaces only the year portion — giving you UBa23R0321. The student digits and middle characters are kept unchanged.
The year-correction triggers when the spoken word is letters immediately followed by exactly 2 digits starting with 2 (matching current-decade years like 20, 21, 22 … 29), and the cell already has a value with the same letter prefix.
2. "Sorry" Correction (fix the previous row)
After the system auto-advances to the next row, say sorry followed by the correction to fix the row you just left:
•
Say sorry UBa23 → goes back one row and changes the year from 25 to 23 (e.g. UBa25R0321 → UBa23R0321).
•
Say sorry 463 → goes back one row and replaces the trailing digits (e.g. UBa25R0321 → UBa25R0463).
•
Say sorry now 21 003 → goes back one row and fixes both the year and trailing digits in a single step (e.g. UBa23R0131 → UBa21R0003). Works with sorry n 21 003 or sorry no 21 003 too.
•
Say sorry now 21 → goes back one row and swaps only the year, leaving the existing trailing digits unchanged (e.g. UBa23R0321 → UBa21R0321).
After the correction you stay on the current row and can continue normally.
3. "Now" Year Override (change the year for this cell only)
When the common prefix is set to e.g. UBa25R0 but a student's matricule uses a different year, say now YY before entering that student's digits. The words now, no, and n all activate this command — the system accepts all three in case speech recognition mishears you:
1
Say now 23 — the system acknowledges the year override and waits. The status bar shows "Now command — say the year". The common prefix for this cell becomes UBa23R0.
2
Say the remaining digits, e.g. 021 — the cell is filled with UBa23R0021.
One-breath shortcut: Say everything at once — now 23 021 fills the cell immediately with UBa23R0021. Also works as n 23 021 or no 23 021. The year override applies only to that one cell — the next row reverts to the normal common prefix.
Two-step trigger: If speech recognition returns just now (or n / no) without any digits, the system arms the trigger and waits. Your next spoken digits are automatically prefixed with "now " so the year override still fires correctly.
⚙️ Row Operations
☑ Selecting Rows
•
Tick the checkbox on the left of any row to select it. A count badge shows how many rows are selected.
•
Tick the top-left checkbox (in the header) to select or deselect all rows at once.
•
Shift-click a second checkbox to select a range of rows between the first and second click.
↑ Toolbar Buttons
•
↑ Up / ↓ Down: Move selected rows up or down in the table. Useful when you need to reorder students.
•
+ Row: Insert a new blank row below the last selected row.
•
🗑 Delete: Remove the selected rows entirely. A confirmation dialog appears.
•
✕ Clear: Wipe the matricule out of selected rows, keeping the rows in place.
The small ↑ ↓ ✕ buttons on the right side of each row move or clear that individual row without needing to select it first.
📂 Files
📁 My Files Tab
All your saved exam sheets live here. Files are organised in folders you create yourself.
•
Open a file: Tap any file card. A preview modal appears with options to open it in the Builder, download, share, or rename it.
•
Open a folder: Tap any folder to navigate inside it. Use the breadcrumb bar at the top or the back arrow to go back.
•
+ Folder: Creates a new folder in the current location.
•
Import CSV: Brings in a previously exported CSV file and saves it as a new file in the current folder.
•
Sort & View: Sort files by Name, Date, or Type. Switch between Tiles and List views.
•
Bin (Recycle Bin): Deleted files go here first. Tap Bin to review and restore or permanently delete them.
Right-click (or long-press on mobile) any file or folder to open a context menu with rename, move, share, and delete options.
🌐 Unified Folders Tab
Unified Folders are shared workspaces that multiple users can contribute files to. They are commonly used by departments to collect exam sheets from several lecturers into one place.
•
Joining a Unified Folder: Another user with access shares a link or folder ID with you. Open it from Files → Unified Folders.
•
Password-protected folders: Some Unified Folders require a password. Enter it when prompted.
•
Contributing a file: Select a file in My Files, then use the action bar's Move to Unified Folder button to send it there.
•
Opening from a Unified Folder: Files inside a Unified Folder open in the Builder just like your own files. Changes are saved back to the shared folder.
🎓 Student Dictionary
🎓 What is the Student Dictionary?
The Students page holds a shared database of student names keyed by matricule number. Once populated, the Builder automatically shows each student's name below their matricule as you fill in cells — giving you instant confirmation that you are entering the right code.
Student names are visible inside the app only. All downloaded documents (CSV exports) contain only matricule numbers — names are never written to files.
📄 Uploading the Student List (Admin Only)
Only a Super-admin account can add or modify the dictionary. The easiest way to populate it is to upload a CSV file:
1
Go to Students in the navigation bar.
2
Click ⇧ Upload CSV. The file must have a header row with columns named matricule and name (order does not matter). Tab-separated files are also accepted.
3
If any matricule in the CSV already exists in the dictionary, a conflict dialog lets you skip duplicates (keep existing names) or overwrite them.
4
Click + Add Student to add individual entries one at a time.
The system enforces one name per matricule. Attempting to add a matricule that is already in the dictionary triggers a warning before any change is made.
🔍 Searching and Sorting
All users (not just admins) can search and sort the dictionary:
•
Use the search bar to filter by any part of a name or matricule.
•
Click Sort to toggle between Matricule order and Name (alphabetical) order.
⇩ Downloading the Dictionary (Admin Only)
Super-admins can download the full dictionary as a CSV file using the ⇩ Download CSV button. The file contains two columns: matricule and name. Regular users do not see this button.
🔍 Student Lookup
🔍 Finding a Student's Exam Code
The Lookup page lets you find any student across all of your saved files using their matricule number.
1
Go to Lookup in the navigation bar.
2
Type the student's matricule (e.g. UBa25R0357) in the search box.
3
Press Enter or click Search.
4
All matching entries are shown — each one showing the course code, exam code, and the file it came from.
You can search for a partial matricule — the search finds any entry that contains what you typed.
⚙️ Settings
⚙️ Configuration Options
•
Auto-advance after silence: When on, voice input automatically moves to the next row after the silence timeout expires. Turn off if you prefer to advance manually (press Enter).
•
Auto-prepend prefix: When on, the Matricule Prefix is automatically prepended to voice input (so you only speak the digits). Turn off if you prefer to always speak full matricule numbers.
•
Expected matricule length: Set how many characters a valid matricule should have (default 10). Rows with a different length are highlighted in orange as a warning.
•
Enforce character limit: When on, matricule cells stop accepting input once they reach the expected length. Voice input is also truncated to this length.
•
Auto-save enabled: Saves your work to the cloud every 30 seconds automatically. Recommended to keep on.
•
Course Dictionary: A saved list of your frequently used course codes and their titles. When you type a code in the Builder, matching dictionary entries appear as autocomplete suggestions. Add, edit, or remove entries here.
•
Install App: Install ExamCode as a standalone app on your device. See Getting Started → Installing on Your Device above.
🎨 Row Highlights Explained
🎨 Colour Coding
Rows in the Builder are colour-coded to give you instant feedback:
Active row (cyan/blue): The row currently selected for input. Moves as you navigate between cells or as voice advances.
Duplicate (red): Two or more rows share the same matricule. A DUPE badge also appears on the exam code. Correct one of the values to clear the warning.
Wrong length (orange): The matricule in this row is shorter or longer than the Expected matricule length set in Settings. Fix the matricule or adjust the expected length.
Orange and red highlights are warnings only — you can still export the file. Use them to spot typos before submitting.
🎤 Voice Commands Quick Reference
🎤 What You Can Say
What you sayWhat happens
321Sets the current cell to prefix + 321 (e.g. UBa25R0321). Auto-advances after silence.
UBa25R0321Sets the current cell to exactly UBa25R0321 — no extra prefix added when input already contains letters.
UBa23Year correction: If the current cell already contains UBa25R0321, changes it to UBa23R0321. Only the year digits change.
now / n / noNow trigger (standalone): Arms the year-override mode. Status bar shows "Now command — say the year". Your next spoken digits are treated as now <digits> automatically.
now 23 021Now (single utterance): Immediately fills the current cell with UBa23R0021, overriding the year in the common prefix. Also works as n 23 021 or no 23 021.
now 23Now (two-step): Arms the year override to 23 and waits for you to say the remaining digits on the next breath.
sorry 463Sorry correction: Goes back one row and replaces the trailing digits — e.g. UBa25R0321 → UBa25R0463.
sorry UBa23Sorry correction: Goes back one row and applies a year correction — e.g. UBa25R0321 → UBa23R0321.
sorry now 21 003Sorry + Now (combined): Goes back one row and fixes both the year and trailing digits at once — e.g. UBa23R0131 → UBa21R0003. Works with sorry n 21 003 or sorry no 21 003 too.
sorry now 21Sorry + Now (year only): Goes back one row and swaps just the year, leaving the existing trailing digits untouched — e.g. UBa23R0321 → UBa21R0321.
Prerequisite: Voice commands only work while the microphone is active (mic button is red). Make sure your browser has microphone permission for the app.
💡 Tips for Better Voice Recognition
•
Speak clearly and at a normal pace. Shouting or whispering reduces accuracy.
•
Reduce background noise when possible. Close windows, turn off fans, and move away from loud areas.
•
For digits, say each number individually: "three two one" works better than "three hundred twenty-one" in most cases.
•
If the silence timeout is triggering too early, increase it with the Silence Timeout slider and click Apply Changes.
•
If the mic stops unexpectedly, tap it again to restart — it will continue from the same row.

If you are still having difficulty, contact your system administrator. Provide as much detail as possible about what you were doing and what unexpected behaviour you observed.
