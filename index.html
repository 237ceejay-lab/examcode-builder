ExamCode UBa
University of Bamenda — Exam Management System
A powerful tool for building and managing exam code sheets. Assign matricule numbers to exam codes quickly using voice input, manage files, and look up students across all courses.
🎤
Voice InputSpeak matricule numbers hands-free — auto-advances to the next row after each entry.
📄
Generate SheetsInstantly create numbered exam code tables for any course and export as CSV.
🔍
Student LookupSearch any matricule across all saved files to find a student's exam codes.
📂
File ManagementOrganise sheets into folders, import CSV files, rename, move and download.
